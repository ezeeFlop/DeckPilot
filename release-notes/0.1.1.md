## Automatic updates

DeckPilot can now update itself. It checks the release feed on GitHub, downloads the new
version and installs it; every update is signed. You can check by hand from the DeckPilot
menu or the menu bar icon, and turn automatic checks off there.

Version 0.1.0 has no updater: install this version by hand once, and later ones will arrive
on their own.
