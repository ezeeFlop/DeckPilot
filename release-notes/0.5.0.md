## Stream Deck plugins

DeckPilot can now host plugins written for Elgato's Stream Deck with the official Node.js
kit. A plugin draws its keys, receives their presses and shows its own settings page in the
panel.

Select a key, then under **Plugin** use **Install a plugin…** with a `.sdPlugin` folder or a
`.streamDeckPlugin` file, and hand the key to one of the plugin's actions.

Node.js must be installed on the Mac. Plugins written as an HTML page, dials, touch strips
and profile switching are not supported. This first version has been tried with one plugin.
